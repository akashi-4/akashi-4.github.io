# João Furukawa — CV

Personal CV site in the style of Counter-Strike 1.6, live at **https://akashi-4.github.io**.

- `index.html` — the page (main menu + desktop with CV windows)
- `game.js`, `game.css` — optional walkable 3D map (`New Game` on the menu), built with three.js
- UI styling from [cs16.css](https://github.com/ekmas/cs16.css) (MIT)
